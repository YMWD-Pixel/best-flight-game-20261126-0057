**Azure Isles — Sky Courier.** A 3D bush-plane flight game over a procedural archipelago: take off from Coral Bay, thread glowing rings over beaches, snowy peaks and open sea, mind your fuel, and put the plane down gently on three island airstrips. Three missions — Ring Run (10 rings against the clock), Island Hop (land on all three strips in order) and Free Flight (collect 12 drifting cargo crates) — with a full HUD (speed, altitude, heading compass, fuel, throttle, live minimap), synthesised engine/wind/ring sounds, and an arcade flight model with stalls, banking turns and hard landings that end the flight.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

No build step, no network: `game/` is plain static files (Three.js is vendored under `game/vendor/`). Play with keyboard (arrows/WASD to fly, W/S throttle, Space brake, P pause, M mute) or mouse (hold the left button and steer).
